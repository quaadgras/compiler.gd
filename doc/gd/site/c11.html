What does it do?

  1. Each .go file becomes a .c file; each package a private and a public .h.
  2. A small, replaceable <go.h> holds the runtime and the builtin types.
  3. The standard library compiles from Go's source, with a few C11 hooks (os, parts of reflect).
  4. Errors are reported exactly as gc reports them (it uses gc's parser).

Why C?

  1. Fil-C: memory-safe C, so unsafe code is checked and data races can't corrupt the runtime.
  2. Cosmopolitan Libc: one binary for Linux, macOS, Windows and the BSDs.
  3. Calling C is just calling C (no cgo trampolines).

Try it

go install github.com/quaadgras/gd-compiler@latest
cd your/go/package
gd-compiler build

The output needs a garbage collector: link Boehm GC, or use a C compiler that has one (Fil-C). Set the compiler with GD_CC.
