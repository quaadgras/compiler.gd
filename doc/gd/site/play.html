How it works

  
    
    
  • The page downloads the go command for GOOS=js (24 MB, once: your browser keeps it) and the standard library's source, and runs go build in a worker. compile and link are part of that one binary.
    • 
    
  • Programs are built for js/wasm on the WebAssembly GC runtime (GOWASM=gc,split): each allocation keeps its bytes in linear memory and its pointers in a WebAssembly GC array, so the browser’s collector frees it.
    • 
    
  • The build cache lives in IndexedDB. Common packages come precompiled; anything else is compiled on first use (a minute or so for a large package), then cached.
    • 
    
  • Only the standard library: there's no network access for modules. Press Ctrl+Enter to run.
    • 
    
  • Needs WebAssembly GC and JavaScript Promise Integration: Chrome 137, Firefox 153, Safari 27.
