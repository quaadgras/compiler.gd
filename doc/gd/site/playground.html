    How it works
    
    
      
  1. The go command for GOOS=js (24 MB, downloaded once) builds in a worker; compile and link are part of it.
    2. 
      
  2. Programs run on the WebAssembly GC: bytes in linear memory, pointers in GC arrays, freed by the browser's collector.
    3. 
      
  3. The build cache lives in IndexedDB. Common packages come precompiled; others compile on first use.
    4. 
      
  4. C works through cgo's import "C", translated by the fork's own C front end (cc), which bounds-checks every access.
    5. 
      
  5. Code that doesn't start with package is C, run from its int main(void).
    6. 
      
  6. Standard library only (no modules). Ctrl+Enter runs.
    7. 
      
  7. Needs WebAssembly GC and JSPI: Chrome 137, Firefox 153, Safari 27.
